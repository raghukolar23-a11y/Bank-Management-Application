# Bank Management System (C++)

## Project Overview
The Bank Management System is a console-based application developed using C++.  
This project simulates core banking operations such as account creation, deposit, withdrawal, and balance inquiry using Object-Oriented Programming (OOP) concepts and file handling.

The system securely stores customer records using binary files and provides persistent data storage.

---

## Features
- Create New Bank Account
- Deposit Money
- Withdraw Money
- Balance Inquiry
- Display Customer Details
- File Handling for Data Storage
- Persistent Customer Records

---

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling (`fstream`)
- Binary File Storage

---

## OOP Concepts Used
| Concept | Usage |
|---|---|
| Class & Object | `BankAccount` class |
| Encapsulation | Private data members |
| Abstraction | Banking operations through methods |
| File Handling | Store and retrieve records |
